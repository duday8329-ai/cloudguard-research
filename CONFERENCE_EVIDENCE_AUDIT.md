## Critical implementation mismatch

The old paper claims an Abstract Resource Graph, AST-based repairs, context
multipliers, compensating-control factors, and two native validation gates.
The deployed CloudGuard capstone currently provides a browser-side file reader,
five pattern-based policy checks, transparent deductions, findings, and
remediation guidance. It does not currently provide a general ARG, AST rewrite
engine, Terraform plan validation, CloudFormation template validation, or
automatic remediation execution.

The old paper also lists nine policies. The current project implements five:
public S3, public RDS, unrestricted ingress, wildcard IAM actions, and disabled
RDS encryption. Therefore, the old system description and Table I must be
reduced or the missing functionality must be implemented and tested.

## Submission-safe paper direction

Retitle and scope the paper around the implemented system, for example:

> CloudGuard: Explainable Policy Violation Detection and Remediation Guidance
> for AWS Infrastructure as Code

State that CloudGuard currently produces remediation guidance, not verified
automated repair. Report the 12-manifest run only as an implementation sanity
check, or omit its 1.0000 values from the paper entirely. The conference paper
should contain measured comparative values only after the next experiment.

## Required measurements before a results paper

1. Grow the benchmark to a declared, real size and preserve every file.
2. Freeze the policy mapping and run CloudGuard, Checkov, KICS, and Trivy.
3. Save raw predictions and normalize them to the policy-instance unit.
4. Run `calculate_metrics.py` per analyzer and format directly from output.
5. Obtain real independent labels for ranking or remove RQ2.
6. Implement and validate automatic remediation before retaining RQ3/Gate claims.
7. Instrument the actual system before retaining latency/scalability claims.
8. Remove the practitioner study unless it is genuinely conducted with consent.

Until these steps are complete, replace every historical numerical result with
`not measured`, `planned`, or remove the table.
